# 公开源码使用说明

本仓库发布最终整理版源码，不包含作者的密钥、数据库、顾客上传图片、真实收款码或已打包的客户端。

## 安装与演示

准备 Java 17 或以上版本、Maven、Node.js 和 Windows 微信开发者工具，然后安装前端依赖并构建后端：

```powershell
npm --prefix admin-web ci
npm --prefix desktop ci
mvn -B package
```

后端默认配置使用本机 H2 演示数据库。可以在项目根目录运行：

```powershell
java -jar backend/target/billiard-server-0.1.0.jar
```

演示服务监听 `http://127.0.0.1:8080`。默认演示管理员为 `admin`，密码为 `Admin123!`。正式部署通过 `ADMIN_PASSWORD`、`DB_PASSWORD` 等环境变量设置自己的凭据，MySQL 配置使用 `mysql` profile。

启动网页开发服务：

```powershell
npm --prefix admin-web run dev
```

网页地址为 `http://127.0.0.1:5173`；Vite 将 `/api` 转发至本机后端。也可以运行 `npm --prefix desktop start`，在客户端的服务器设置中填写自己的业务服务器地址。

## 微信小程序

使用微信开发者工具打开 `miniprogram` 目录。将 `project.config.json` 中的 AppID 和 `app.js` 中的 `baseUrl` 改为自己的配置；正式微信登录的 `WECHAT_APPID`、`WECHAT_SECRET` 仅配置在服务器。

真实微信收款码未公开。部署时把自己的二维码图片分别放在：

- `miniprogram/assets/store-qr.png`
- `admin-web/public/store-qr.png`

如使用完整收款海报的页面，还需配置 `miniprogram/assets/store-payment.jpg`；桌面端历史海报文件 `admin-web/public/store-payment.jpg` 同样不随公开源码发布。

系统中的体验充值和扫码演示流程用于项目展示，不代表已接入微信支付或支付宝商户真实扣款接口。

## 验证与桌面构建

```powershell
npm --prefix admin-web run check
npm --prefix admin-web run format:check
npm --prefix admin-web run check:mini
npm --prefix admin-web run test:ui
npm --prefix desktop run pack
```

`check:mini` 需要 Windows 微信原生编译器，安装位置不同时设置 `WECHAT_WCC_DIR`。代码结构与格式规范见 [源码维护说明](源码维护说明.md)。

云端部署可参考 `deploy` 下的环境变量示例、Docker Compose 与服务器脚本。仓库不包含作者正在使用的服务器密码、SSH 私钥或数据快照。
