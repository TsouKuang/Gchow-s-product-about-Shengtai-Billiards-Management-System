# 最终版源码维护

本次整理保留最终版界面和业务规则，集中清理旧样式、无引用方法和重复配色数据，并统一源码格式。

## 小程序

`miniprogram/pages/home/home.js` 负责页面状态、生命周期、登录与球桌入口。其余功能通过方法模块组合，页面模板中的事件名称保持一致。

| 文件 | 职责 |
| --- | --- |
| `pages/home/profile.js` | 个人资料、会员与皮肤选择 |
| `pages/home/orders.js` | 订单展示、账单、结算与历史管理 |
| `pages/home/services.js` | 助教与球杆筛选、服务预约 |
| `pages/home/wallet.js` | 钱包、余额隐藏、充值与支付密码 |
| `pages/home/club.js` | 球力榜 |
| `pages/home/appearance.js` | 基础与专属皮肤的唯一配色定义 |
| `pages/home/labels.js` | 球桌、订单及结算状态文字 |
| `pages/home/home.wxml` | 主要页面内容与弹层引用 |
| `pages/home/views/` | 支付结果、预约、钱包、提示和扫码支付弹层 |

页面和弹层共用 `themeStyle`。新增弹层时需要带上 `app-themed` 类和 `style="{{themeStyle}}"`，避免出现不跟随皮肤的区域。

余额显示必须遵守 `walletHidden`。该设置按账号保存在本机，隐藏只影响展示，不改变余额数据和支付判断。

## 格式、检查与构建

先在 `admin-web` 和 `desktop` 执行 `npm ci` 安装依赖，然后在项目根目录运行：

```powershell
npm --prefix admin-web run format
npm --prefix admin-web run format:check
npm --prefix admin-web run check
npm --prefix admin-web run check:mini
npm --prefix admin-web run test:ui
npm --prefix admin-web run build
npm --prefix desktop run pack
```

微信原生编译检查需要 Windows 微信开发者工具；安装位置不同时可用 `WECHAT_WCC_DIR` 指定 `wcc.exe`、`wcsc.exe` 所在目录。

`prettier.config.cjs` 统一 JavaScript、CSS、WXSS、JSON 和 Electron 设置页面的格式。WXML 与工作台模板由 `scripts/format-markup.cjs` 排版，保留混合文本和插值表达式，避免普通 HTML 换行改变金额标签或拆开字符串。

`check` 检查 JavaScript 语法、重复属性、重复小程序方法、模板事件引用和工作台模板。`test:ui` 检查皮肤、账号隔离与余额隐藏行为。

不要直接编辑 `admin-web/dist`、`desktop/web` 或桌面打包目录。桌面打包会先构建前端，再同步静态文件；数据库、上传图片、历史迁移和 `.local` 私有配置不属于源码清理范围。
